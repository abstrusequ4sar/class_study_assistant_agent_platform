# 课程学习助手 Agent 平台新版汇报大纲

1. 封面：项目名称、课程名称、汇报信息
2. 为什么做：资料分散、重点难找、计划不清、任务易漏
3. 项目目标：围绕课程建立“资料—问答—计划—任务”学习闭环
4. 需求完成全景：基本功能、高级功能和工程增强对照
5. 系统总体架构：Vue 前端、FastAPI 后端、Agent/检索服务、SQLite/文件存储、外部模型
6. 核心数据与学习闭环：8 张表和主要业务数据流
7. 用户认证：JWT、PBKDF2、路由守卫与登录态恢复
8. 个人中心：课程、计划、任务和对话统计入口
9. 课程管理：课程 CRUD、归属隔离、响应式卡片
10. 课程资料管理：拖拽批量上传、队列校验、分类、筛选、下载、删除和文件安全
11. 多格式解析与资料检索：TXT/MD/PDF/DOCX/PPTX、切片、向量检索与关键词降级
12. 完整 Agent 对话：10 个工具、最多 8 轮决策、流式/非流式统一
13. 资料来源展示：稳定编号、片段摘录和历史引用快照
14. 资料来源跳转：material_id 路由参数、跳转提示与目标高亮
15. 知识点整理：全部切片覆盖、章节自然排序、3 批并行、SSE 进度和来源关联
16. 单课程学习计划：目标、截止日期、每日时长转为阶段与每日任务
17. 智能任务拆解：结构化 JSON、参数校验、批量落库、最多 60 条任务
18. 多课程综合规划：多目标、多截止日期、课程归属校验与时间分配
19. 待办任务、日历与提醒：三种任务来源、CRUD、状态筛选、到期分组
20. RESTful API 与数据存储：34 个 OpenAPI 操作、分层路由、ORM 和可替换配置
21. 可用性、安全与降级：数据隔离、XSS 消毒、秘钥隔离、关键词/规划降级
22. 测试与结果：后端 45 项、前端测试、生产构建、协议/越权/安全验证
23. 项目亮点与优势：可执行 Agent、可核查引用、双协议、在线离线统一、学习闭环
24. 总结与演示路线：从资料入库到引用跳转、计划与任务反馈

视觉要求：16:9，白底、深蓝标题栏、少量浅蓝/浅绿强调；只使用可编辑文字、简单形状、表格和真实界面截图。
